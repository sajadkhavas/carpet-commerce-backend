# B00 — Foundation & Architecture

## Goal

Create a production-oriented Django foundation that later domain phases can extend without
reworking infrastructure.

## Baseline

- Repository bootstrap commit: `49e610e3f2fef204e58f8da266b7f5ae227e6dbb`
- Branch: `phase/b00-foundation-architecture`

## Acceptance criteria

- [x] Python 3.13 runtime selected.
- [x] Django 5.2 LTS and DRF foundation defined.
- [x] Development, test and production settings separated.
- [x] PostgreSQL and Redis configuration is environment-driven.
- [x] Celery is wired using Django settings.
- [x] OpenAPI schema and Swagger route are available.
- [x] Health and readiness endpoints exist.
- [x] Request IDs are propagated/generated for traceability.
- [x] Docker Compose provides API, worker, PostgreSQL and Redis for local integration.
- [x] Ruff, pytest and Django checks are part of CI.
- [x] OpenAPI generation/validation is part of CI.
- [x] No secrets are committed.
- [x] Architecture and backend roadmap are documented.
